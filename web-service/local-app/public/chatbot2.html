    무슨 약물이 궁금하신가요?

    3제 이상
    • 약 이름이나 성분명을 정확히 적을수록 근거를 잘 찾습니다.
    • 답변은 근거 탐색용이며 의료진의 판단을 대체하지 않습니다.

    미리 실행해 저장한 실제 답변을 다시 보여 줍니다. 모델을 호출하지 않아 비용이 들지 않고, 답변 내용은 누를 때마다 같습니다. 의약품안전사용서비스(DUR)·허가사항 조회와 원문은 지금 연결된 DB에서 가져옵니다. 대화 칸의 "구체적인 답변 보기"를 켜면 같은 질문을 따로 실행해 저장한 구체적인 답변을 보여 줍니다. 따로 실행한 답변이라 판단, 근거 번호, 관계도가 간단한 답변과 다를 수 있습니다.

      API 키

      질문에 답할 때 씁니다. 쓴 만큼 이 키의 OpenAI 계정에 요금이 나갑니다.
      노드 사전에 의약품안전나라 허가정보를 보여 줄 때 씁니다. 무료입니다.

      OpenAI API 키 만들기

      1. platform.openai.com에 로그인합니다. ChatGPT 구독과는 따로이며, API는 쓴 만큼 요금이 나갑니다.
      2. Settings의 Billing에서 결제 수단을 등록하고 크레딧을 충전합니다(최소 $5). 자동 충전(auto-reload)은 처음에 켜져 있으니, 원하지 않으면 끄고 충전하세요.
      3. API keys 화면에서 Create new secret key를 누르고, 만든 키를 바로 복사해 위 칸에 붙여 넣습니다. 키 전체는 만들 때 한 번만 보입니다.

      비용: 질문 하나에 약 $0.005~0.01(10원 안팎)입니다. gpt-4o-mini 요금으로, 시범 실행 11회에 쓴 양을 바탕으로 계산했습니다.

      공공데이터포털 인증키 받기 (선택)

      1. 식품의약품안전처_의약품 제품 허가정보 페이지에서 로그인한 뒤 활용신청을 누릅니다. 승인 방식은 그 페이지에 나옵니다.
      2. 마이페이지의 오픈API 개발계정에서 이 서비스를 열고, 일반 인증키(Decoding)를 복사해 위 칸에 붙여 넣습니다. Encoding 키를 넣어도 됩니다.

      이 키를 넣지 않아도 서버에 키가 있으면 허가정보가 나옵니다. 둘 다 없으면 노드 사전에 HyperRx 요약이 나옵니다.

      키 보관

      • 키는 이 브라우저에만 저장됩니다. 기억하기를 끄면 이 탭을 닫을 때 지워집니다.
      • 질문할 때만 요청 헤더에 담아 이 서버로 보냅니다. 서버는 그 질문을 처리하는 동안만 쓰고, 저장하거나 기록하지 않습니다.
      • 공용 컴퓨터에서는 기억하기를 켜지 마세요. 키가 새어 나갔다고 생각되면 OpenAI의 API keys 화면에서 그 키를 바로 삭제(Revoke)하세요.

      계정

      내 계정로그인 기능은 아직 없습니다. 질문 기록은 이 브라우저 탭에만 남고, 새로고침하면 사라집니다.

      사용 안내

      1. 궁금한 약이나 조합을 질문하면 HyperRAG가 근거 문서와 관계를 찾아 답합니다.
      2. 가운데 관계도에서 노드를 누르면 그 노드가 든 관계만 남고, 다시 누르면 전체로 돌아갑니다. 색 영역이나 아래 목록의 관계를 누르면 그 관계만 볼 수 있습니다.
      3. 왼쪽 아래 복용 약에 현재 약을 넣고 새로 추가할 약을 적으면, 추가했을 때 생기는 관계를 따로 보여 줍니다.
      4. 오른쪽 대시보드의 종합 판정은 의약품안전사용서비스(DUR) 병용금기, 허가사항, AI 답변을 정해진 순서로 합쳐 정합니다. 기록이 있으면 기록이 우선합니다. 허가사항 문장은 원문 그대로 보여 줍니다.
      5. 대시보드의 숫자는 근거의 개수입니다. 위험 확률이 아니며, 근거가 없다는 것이 안전하다는 뜻도 아닙니다.
